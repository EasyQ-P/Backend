## 3. 바꿀 것 없음 (알림)

- **API-01:** `CONSENT_REQUIRED`가 403이 됐다(회신대로 `error.code`로 분기하면 영향 없음).
- **API-63 서빙 이력:** `requested_by`에는 요청한 관리자의 **표시명**이 온다(내부 ID 아님). 필드 이름은 그대로다.
- **게스트 재입장:** backend가 `easyq_join_retry` HttpOnly 쿠키(입장 후 24시간)를 함께 내려 준다. 브라우저가 처리한다.
- **입장 코드 한도:** 같은 IP 15분 100회. 강의실처럼 여러 청중이 IP 하나를 써도 잘 막히지 않는다.
- **삭제 중인 강연 · 교안:** 내부 상태(DELETING) 동안 강연은 404, 교안은 목록에서 빠진다. 응답 상태값에는 나오지 않는다.
- **판정 모델 적재 · 키워드 검색(BM25) · DB 권한 · 필기 테이블 변경:** 서버 안의 변경이라 화면 영향 없음.
