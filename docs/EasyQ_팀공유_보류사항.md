# EasyQ 팀 공유 및 보류 사항

2026-10-24 · 제출용 설계 본문과 분리한 관리 문서

## 사용자 지시로 보류한 수정사항 5번

- 부하 시험의 시험 시간 및 STT·LLM 실제 호출 여부: 보류. 이번 수정에서 결정하거나 변경하지 않음.
- KURE-v1·bge-m3 임베딩 비교 실험 담당·방식: 보류. 이번 수정에서 결정하거나 변경하지 않음.

## 참조 문서가 필요한 세부 값

- B 파트 4.3·7.4 원문은 현재 제공되지 않음. 학습서버 API는 수정사항 PDF의 7.4.x 계약 번호로 연결했고 실제 경로는 추정하지 않음.
- epochs는 1~10으로 반영. batch_size·learning_rate의 정확한 상하한은 학과 서버 계약을 따르며 UI 상하한 확정은 B 파트 확인 후 반영. 문서에 임의 수치를 넣지 않음.

## 기존 설정값 정리

- 교안 50MiB, 질문 2,000자, 회원 세션 12시간, 운영 자료 30일 등 기존 구현 기본값은 유지. 이번 AI 팀 요청의 신규 합의로 표현하지 않음.
- 모델 timeout 800ms, 후보20개, 검증 FPR4%, 시험 false_answer_rate≤5%, 호스트 SSH 터널 및 4컨테이너 구조는 이번 반영 기준.
- 원문 PDF의 RDS는 사용자가 정한 db 컨테이너의 서비스 PostgreSQL로 대응. 별도 RDS 도입 없음.

## AI 파트 v4 구체화 권장 규칙

- 5단어 중복 비율의 분모와 전처리는 AI 원문에 상세 정의가 없어, 6.1.6의 작은 집합 기준 겹침 비율 및 공통 함수 버전을 권장 설계로 명시했다.
- 교안 비교 파일은 운영 배포로 갱신하며 전체 평가셋은 복제하지 않는다. 파일 누락·버전 불일치 시 후보 수집을 보류한다.
- 미검수 자동 이관 정리는 새 데이터셋 생성 성공 후 요청 시점 이전 후보에 한정한다. 이미 검수 중인 후보는 제외한다.
- 5번 협의 항목 및 B 파트 경로·파라미터 확인 보류는 유지한다.
